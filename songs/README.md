# Песни

Каждый файл `*.cho` — одна песня в формате ChordPro. Файлы из этой папки
попадают в сборку и доступны в приложении офлайн. Добавили файл, закоммитили,
запушили — GitHub Actions пересобрал и выложил.

Имя файла — латиницей или кириллицей, без разницы; заголовок берётся из `{title}`,
а если его нет — из имени файла.

## Шпаргалка

```
{title: Ой, то не вечер}
{artist: Народная}
{key: Am}
{capo: 0}

{sov: Куплет 1}
[Am]Ой, то не вечер, то не [Dm]вечер,
Мне ма[Am]лым-мало с[E7]палось,
{eov}

{soc: Припев}
[Am]Ой, да во [E7]сне приви[Am]делось.
{eoc}

{c: проигрыш: Am Dm E7 Am}
```

- `[Am]` — аккорд ставится прямо перед слогом, на котором меняется.
- `{title}`, `{artist}` (или `{subtitle}`), `{key}`, `{capo}`, `{tempo}` — метаданные.
- `{sov}`…`{eov}` — куплет, `{soc}`…`{eoc}` — припев, `{sob}`…`{eob}` — бридж.
  После двоеточия можно дать подпись: `{soc: Припев}`.
- `{chorus}` — повторить последний припев.
- `{c: текст}` — комментарий (проигрыш, «2 раза» и т. п.).
- `{sot}`…`{eot}` — табулатура (моноширинный блок).
- Пустая строка разделяет куплеты и без директив.
