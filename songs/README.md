# Песни

Формат — ChordPro, один файл `*.cho` на песню. **Папка в git не попадает** (см. `.gitignore`):
тексты авторских песен в публичный репозиторий не выкладываем.

## Как песни попадают в приложение

1. **Через «Файлы» (основной путь).** Положите `.cho` в iCloud Drive, на iPhone в приложении:
   Главная → «⋯» → «Импорт .cho из Файлов» (можно выбрать сразу несколько). Песни хранятся
   в IndexedDB на устройстве. Повторный импорт файла с тем же названием и исполнителем
   обновляет песню, а не создаёт дубль. Бэкап — «Резервная копия» там же.
2. **Через репозиторий (только то, что можно публиковать — народные песни).** Добавьте в
   `.gitignore` строку `!songs/имя.cho`, закоммитьте — файл попадёт в сборку и будет
   доступен офлайн без импорта.

## Конвертер

`pnpm convert` превращает «аккорды над текстом» из `songs/inbox/*.txt` в `.cho`
(см. `inbox/README.md`). Чтобы файлы сразу оказывались в iCloud Drive, укажите папку:

```sh
pnpm convert --out ~/Library/Mobile\ Documents/com~apple~CloudDocs/Аккорды
```

или один раз создайте `.env.local` (не коммитится):

```
CHORDS_OUT=~/Library/Mobile Documents/com~apple~CloudDocs/Аккорды
```

## Шпаргалка по формату

```
{title: Ой, то не вечер}
{artist: Народная}
{key: Am}
{capo: 0}

{sov: Куплет 1}
[Am]Ой, то не вечер, то не [Dm]вечер,
Мне ма[Am]лым-мало с[E7]палось,
{eov}

{soc: Припев}
[Am]Ой, да во [E7]сне приви[Am]делось.
{eoc}

{c: проигрыш: Am Dm E7 Am}
```

- `[Am]` — аккорд ставится прямо перед слогом, на котором меняется.
- `{title}`, `{artist}` (или `{subtitle}`), `{key}`, `{capo}`, `{tempo}` — метаданные.
- `{sov}`…`{eov}` — куплет, `{soc}`…`{eoc}` — припев, `{sob}`…`{eob}` — бридж,
  `{sop: Вступление}`…`{eop}` — любая другая часть. После двоеточия — подпись.
- `{chorus}` — повторить последний припев.
- `{c: текст}` — комментарий (проигрыш, «2 раза» и т. п.).
- `{sot}`…`{eot}` — табулатура (моноширинный блок).
