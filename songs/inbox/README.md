# Входящие

Сюда кладите песни в формате «аккорды над текстом» — как их копируют с сайтов
или пишут от руки. Имя файла: `Артист - Название.txt`.

```
Вступление: Am F C G

Куплет 1:
Am              F
Я сижу и смотрю в чужое небо
C               G
Из чужого окна

Припев:
      F        G       Am
Но если есть в кармане пачка сигарет
```

Затем `pnpm convert` — получите `songs/<artist>-<title>.cho`, а исходник
переедет в `inbox/done/`. `pnpm convert --dry` покажет результат без записи.
